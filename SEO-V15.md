# AEM GROUP V15 — SEO Architecture

Built from V14 with no visual redesign.

## Added
- Stronger localized metadata for service pages.
- Service + WebPage structured data with accurate Antalya service area.
- Open Graph site metadata and alternate locale metadata.
- Author metadata.
- Existing canonical, hreflang, sitemap, robots, LocalBusiness and Service structures preserved.
- Existing V10/V11 visual assets, reviews, contact buttons and layout preserved.

## SEO principle
No hidden keyword stuffing, fake reviews, fake ratings, doorway pages, or invented business claims.

## Deployment
Upload the contents of this package into the existing GitHub project folder used by the current Vercel deployment. Do not delete the Vercel project or domain.
